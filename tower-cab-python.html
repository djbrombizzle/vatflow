Python setup

The closures helper (the small tool that puts barricades, X's and work vehicles into the sim) is a Python script, so your PC needs Python once. It takes about five minutes. You only need this for closures: the Tower Cab itself works without Python.

1

Check if you already have it

Press Windows key + R, type cmd and press Enter. In the black window type:

py --version

If it prints something like Python 3.12.7 (3.9 or newer), you're done here: skip to step 4. If it says "not recognized", or a Microsoft Store window opens, go on to step 2.

2

Download Python

Go to python.org/downloads/windows and download the Windows installer (64-bit) of the latest Python 3.12 or 3.13 release.

Or, if you're comfortable with the command line, this does the same in one go (in the cmd window):

winget install -e --id Python.Python.3.12
3

Install it, with "Add python.exe to PATH" ticked

Run the installer. On its first screen, tick "Add python.exe to PATH" at the bottom (it's off by default), then click Install Now. If Windows asks for permission, say Yes. When it says "Setup was successful", click Close.

Then close every cmd window you have open. Windows only picks up the new Python in windows opened after the install.

4

Set up the helper

Extract VATFLOW-Closures-Helper.zip (right-click > Extract All; running the files from inside the zip doesn't work). In the extracted folder, double-click 1-setup.bat. It installs the SimConnect package for Python and should end with Setup done. You only do this once.

5

Every session

Start your flight in the Tower Cab, then double-click closures.bat and leave its window open (minimized is fine). On the cab's CLOSURES screen the bottom line turns green: SIM HELPER ON.

If something goes wrong

What you seeWhat to do
Python was not found (from 1-setup.bat)Install Python (steps 2 and 3). Already installed? Close all windows and try again, or restart the PC.
A Microsoft Store page opens when you type pythonThat's a Windows shortcut, not Python. Install from python.org as above. If it still happens: Windows Settings > Apps > Advanced app settings > App execution aliases, turn off the two "App Installer python" entries.
Setup FAILED: pip could not installUsually no internet access for Python (firewall, antivirus or VPN). Allow it and run 1-setup.bat again. The lines above that message say what went wrong.
The window opens and closes at onceYou're running it from inside the zip. Extract it first (step 4).
Helper runs but no objects in the simFully quit and restart MSFS once after installing the cab. Then, with the flight loaded, run closures-test.bat: it puts one of each object in front of the cab.
